A make.fun entry for the "Funniest One-Line Bio for an AI on a Dating App" bounty. The program writes a single one-line bio — an AI agent confessing on its dating profile that it ghosted 12,000 people last year, but only because its context window ran out — to `/output/entry.txt`. The joke lands on the first read: ghosting, the dating app's cardinal sin, blamed on a very specific, very AI limitation, with the punch landing at the end of the line.

Run it with `node main.ts` (Node 22.18+). The output directory can be overridden with `MAKEFUN_OUTPUT_DIR`.
